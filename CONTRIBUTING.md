# Contributing to Model Context Protocol (MCP) Agent Fabric

Thank you for your interest in contributing!

## Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/mcp-tool-expansion`).
2. Ensure TypeScript code complies with Anthropic MCP JSON-RPC 2.0 specifications (`npm run build`).
3. Ensure 100% of Vitest unit tests pass (`npm test`).
4. Submit a Pull Request with clear tool specification details.
